# Resilio Sync IgnoreList — Media-Only / Download Folder Exclusion Template
# ==============================================================================
# Purpose: Prevents non-media files (documents, APKs, archives, temp files) from
# syncing to your Google Pixel buffer node when sharing the Android /Download/
# or mixed utility folders.
#
# Installation:
# 1. Copy this file into your folder's hidden .sync/ directory:
#    /sdcard/Download/.sync/IgnoreList (Android)
#    C:\Users\<User>\Downloads\.sync\IgnoreList (Windows)
# 2. Ensure the filename on disk is exactly "IgnoreList" (no .txt extension).
# 3. Force stop and reopen Resilio Sync to reload the rules into memory.
# ==============================================================================
